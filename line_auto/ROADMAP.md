# LINE自動送信 拡張ロードマップ（札幌＋那覇）

基盤（line-push / line-send / links / config / 送信リスト / バッジ / アップローダー）は完成済み。
各項目：設計 → 実装 → オーナー宛テスト → 本番化(config) → Slack報告。

## 実装2パターン
- **cron型**（期日ベース・完全自動）：`damage-check-cron`方式。5分/日次ジョブで対象を拾い line-push。→ A系・C1・D2・E1。
- **ボタン型**（スタッフ操作・その場送信）：`line-send`方式（📱到着で構築済）。📱OK=自動/📱手動=コピー。→ B系・D1。

## 共通ルール（全施策）
- 宛先＝「予約番号→{store}_line_links→userID」完全一致のみ。未登録は📱手動（送信リスト/コピーで拾う）。
- 誤送信ガード（キャンセル/過去/番号不一致）自動適用。KEYDROPも対象。
- ログは`{store}_line_sends`にaction名で記録（重複送信防止・cron型は必須）。
- テストは必ずオーナーのそのチャネルのuserID宛。本番化はconfigで段階ON。
- **誤情報リスク（住所/ナンバー/金額/時刻）は"確実に取れる時のみ表示・不確実なら省略"**（到着ナンバーで確立した方針）。
