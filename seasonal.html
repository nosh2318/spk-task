📖 シーズナル定義 方法論（共通）

HANDYMAN のシーズナル区分（A繁忙 / B通常 / C閑散）は、4要素を加重平均した総合スコア（0-10点）で機械的に判定する。エリア固有のイベント・観光統計・レンタカー業界動向・連休カレンダーをすべて織り込む。
那覇クラス: A(アルファードH) / B(ワンボックスB) / C(CSUV) / D(ワンボックスD) / F(コンパクト) / H(ハイブリッド)

合計スコア = (E × wE + T × wT + R × wR + H × wH) / (wE + wT + wR + wH)
ティア = 合計スコア ≥ 閾値A → A / ≥ 閾値B → B / その他 → C

④ エリア固有の注意事項

那覹エリア

  • 沖縄は梅雨（5月末〜6月）でも観光客は来る。T/R を他地域ほど下げすぎない
  • 台風シーズン（8〜9月）は直撃日は需要急落。日別上書きで対応
  • 沖縄独自の旧盆（旧暦7月）はお盆とほぼ同時期 → 沖縄全島エイサーとセット
  • 年末年始は本土からの観光客が多く、他地域と同様の超繁忙

札幌エリア

  • 冬（12〜3月）は雪道により一般観光レンタカー需要が大幅減。C になりやすい
  • さっぽろ雪まつり（2月上旬）は例外的に繁忙。E+T のスコアが高い
  • 夏（7〜8月）は年間最高需要。北海道旅行の最盛期
  • 紅葉期（10月上中旬）は週末の需要が高い
