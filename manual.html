⏰ タイムカード（打刻）

概要

各アルバイトが自分の個人リンク（スタッフ専用ページ）から 出勤 / 退勤 / 休憩開始 / 休憩終了 を打刻します。休憩は複数回OK。打刻した時刻がそのまま勤務実績になり、店舗の給与ページに直結します。シフト（計画）に入っていない日でも、打刻すれば実績になります。

正本テーブル＝spk_attendance（1日1スタッフ1行）。休憩は同テーブルの breaks（jsonb・複数回）。修正申請は spk_timecard_requests。

👤 アルバイトの使い方（打刻）

  1. 自分の個人リンク（スタッフ専用ページ・URL: staff.html?t=（自分のトークン））を開く。
  2. 上部タブの 「⏰打刻」 を開く。
  3. 大ボタンで打刻する（状態に応じて押せるボタンだけ光ります）：
    • 🟢 出勤（未出勤のとき）
    • ☕ 休憩開始 → ✅ 休憩終了（勤務中のとき・何回でも）
    • 🔴 退勤（勤務中のとき・休憩中は先に休憩終了）
  4. 押すと確認が1回出ます。今日の状態（出勤・休憩1・休憩2・退勤）が下に表示されます。
スマホのホーム画面に個人リンクを追加しておくと毎日ワンタップで打刻できます。

✏️ 打刻を間違えた・押し忘れたとき（修正申請）

  1. 「⏰打刻」画面の下 「✏️ 打刻を間違えた・押し忘れた（修正申請）」 を押す。
  2. 対象の勤務日を選ぶ：当日だけでなく 過去の勤務日 も申請できます。プルダウンには直近30日で打刻またはシフトがある日が並びます。一覧に無い過去日（押し忘れで記録が無い日）は右の 日付ピッカー（最大60日前まで）で選べます。
  3. 直したい打刻を選ぶ：出勤／退勤／記録済みの休憩○ 開始・終了。押し忘れて休憩の打刻が無いときは 「➕ 休憩を追加 — 開始／終了」 を選び、開始・終了を別々に申請します（両方承認されると休憩1回分になります）。
  4. 正しい時刻・理由を入力して申請。
  5. 申請は 「店舗の承認待ち」 になります。店舗が確認して承認すると その対象日 の実績が直ります。
修正できるのは「時刻」だけです（出退勤・各休憩の開始/終了・押し忘れた休憩の追加）。欠勤・遅刻・シフト外出勤は申請不要（打刻された事実がそのまま実績になります）。

🧑‍💼 店舗（給与ページ）の使い方

本体アプリ → 給与 タブ → 実績（勤怠） サブタブ。スタッフを選ぶと、その月の日別に 計画（シフト）× 実績（打刻）× 判定 が並びます。

計画（シフト）実績（打刻）
出退勤09:00〜18:0009:04〜18:02
休憩60分53分（2回）／差分表示
  • 休憩照合：計画◯分／実績◯分と差分を表示。休憩が取れているか一目で分かります。
  • 修正申請：申請がある日は黄色＋「✏️修正申請中」。上部の申請カードで [✅承認して反映] で実績に反映（1件だけ・打刻時刻を尊重）、[却下] は実績を変えません。休憩の修正は breaks の該当回の開始/終了だけを更新（他の休憩は保持）、休憩の追加は末尾に1回分を足します。
  • 承認：各日の [承認]（未承認のとき）または上部 [まとめて承認] で実績を確定します。承認済みの日は ✓承認済 と表示されます。承認を間違えたときは「✓承認済」をタップ→確認ダイアログで未承認に戻せます（承認取り消し）。
  • 編集：店舗が直接時刻を手直ししたいとき、または打刻がまだ無い日に代理入力したいときは各日の [編集] から。
実績列のボタンは全日 「承認」「編集」 の2つに統一されています（承認＝実績確定／編集＝手直し・代理入力）。給与計算は 承認済みの実働時間に乗ります。実働 =（退勤−出勤）−Σ休憩。打刻の休憩がある日はその実績休憩を控除し、打刻が無い日はスタッフ設定の計画休憩（休憩分）を控除します。

⚙️ 初回セットアップ（オーナー手作業・1回だけ）

  1. Supabase → プロジェクト ckrxttbnawkclshczsia → SQL Editor を開く。
  2. spk_timecard.sql を全文貼付して RUN（spk_attendance.breaks 追加＋spk_timecard_requests＋打刻RPC）。冪等なので複数回RUNしても安全。
  3. 各アルバイトの個人リンク（staff.html?t=…）を配布（スタッフ管理の共有トークンから）。

🅿️ 駐車場マップ（入出庫・入庫時の記録）

概要

TOP →「🅿️ 駐車場」で開きます。全端末リアルタイム共有（他の人の入出庫はすぐ画面に反映）。1台＝1マスで、どの車がどこに停まっているか・鍵の場所・洗車状態・積んでいるシートを一目で確認できます。

画面の見方：空マス＝停められる／🚗車あり＝停車中（車名・ナンバー・各バッジ表示）／点滅「返却使用予定」＝本日返却で戻ってくる車の予約枠。上部の 🕒本日返却予定 チップで担当者・時刻を確認できます。

① 入庫（車を停める）

  1. 空いているマス、または点滅している 「返却使用予定」 のマスをタップ。
  2. 停める車を選ぶ（コインパーキング等は続けて 駐車No を入力）。
  3. 入庫が確定すると、続けて下の 必須3ステップ（洗車 → 鍵 → シート）を順に記録します。背景タップでは閉じられません（記録するまで進みます）。
⚠️ 入庫すると 鍵・洗車の記録はいったんリセットされます（前の車の状態を引き継がない設計）。入庫直後の3ステップで必ず新しく記録してください。積載シートは車に紐づくので保持されます。

②-1 洗車状態（必須・入庫の最初）

4つから1つ選びます。

選択意味
✨ フル内装・外装とも洗車済み
🧹 内装済み内装のみ済み
🚿 外装済み外装のみ済み
❌ 未洗車未洗車（赤バッジで警告表示）

マスには選んだ状態がバッジ表示されます。未選択の車は 🫧洗車未選択 と出ます。

②-2 鍵の場所（必須・洗車の次）

  • ✅ はい（車内に置く） → 🔑車内鍵あり
  • 🚫 いいえ（持ち出す） → 🚫車内鍵なし

未記録の車は ❔鍵未確認 と表示されます。

🔑 まとめて記録：画面右上の 「🔑 全車 鍵を車内に入れた」 ボタンで、駐車中でまだ「車内鍵あり」でない車を 一括で記録できます（退勤前の一括処理に便利）。

②-3 積載シート（必須・最後）

その車に積んでいるシートの台数を選びます（無ければ 0 のまま「保存して完了」）。4種類選べます：

記号意味
CSチャイルドシート（自社の常備）
JSジュニアシート（自社の常備）
RCSR＝レンタル。レンタルチャイルドシート（予約超過時に外部レンタルで借りて貸すシート）
RJSR＝レンタル。レンタルジュニアシート（同上のジュニア版）
R＝レンタルの意味：予約が自社在庫を超えたときに外部でレンタルして用意するシートです。CS/JS（自社常備）と区別するため頭に「R」を付けています。
シートは 車に紐づいて記録されます（＝車が移動・出庫入庫してもシートは付いたまま保持）。マスには CS/JS は水色、RCS/RJS は黄色のバッジで表示されます。

③ 出庫・変更・入れ替え

停車中の車（🚗マス）をタップすると詳細シートが開きます。ここから：

  • 🚙 出庫：マスを空けます（鍵・洗車の記録はリセット）。
  • 鍵／洗車状態の変更：入庫後でもボタンで直せます。
  • シート台数を編集：積載シートを後から修正。
  • 🔄 入れ替え：別のマスへ移動。
  • ↩️ 返却予定に戻す：返却予定マスへ間違って入庫した時に取り消し。

💡 現場のコツ（入庫は必ずこの順番）

停める → 洗車状態 → 鍵 → シート台数。この3つを記録して初めて入庫完了です。洗車が未選択（🫧）・鍵が未確認（❔）のバッジが残っている車は、記録漏れなので気づいたら埋めてください。

🏭 共立自動車保管（共立自動車に預けている車）

  1. 下の ❓所在不明の車両 から車をタップ →「🏭 共立自動車保管」→ 確認した人を選んで「保管にする」。
  2. 空きマスの入庫画面で車を選んで「🏭 共立保管」、または停車中の車をタップして「共立自動車保管へ移す」でも登録できます（停車中だったマスは空きます）。
  3. 登録した車は 🏭共立自動車保管 の一覧に出て、所在不明からは消えます。マスは使わないので空き台数は変わりません。
  4. 共立から戻ってきたら、一覧の車をタップ →「駐車場に戻す（入庫）」でいつもどおり入庫（入庫すると共立保管は自動で外れます）。「保管を解除」は登録だけを取り消します。
共立保管のまま貸し出された車は「貸出中」に表示されます。
