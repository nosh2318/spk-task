🏠 1. 基本操作▶

ログイン（パスコード起動）

APP起動時にパスコードを入力して開きます。

場所：起動時のログイン画面
  1. APPを開く（PWAホーム画面アイコン or URL）。
  2. 起動パスコード 2318 を入力。
  3. Supabaseログイン画面が出たら oshita@g-lines.jp 等のアカウントでログイン。
⚠️ 会計タブは追加コード 1121、スタッフ／給与／経営は 1823 の二重ロック。経理委託の三國様は会計のみ閲覧可。

タブ構成（ナビ）

画面下部・上部のナビから各機能へ移動します。TOPの「日常業務／スタッフ管理／会計／データ・分析／設定」グリッドからも入れます。

場所：ナビゲーション全体
メインタブTOP / お知らせ / CSV / 予算実績 / 実入金CF / 価格表 / 価格戦略 / スタッフ / 出勤簿 / 給与 / 勤怠管理 / 配車 / 決済 / 車両 / 車両ランキング / 車両P&L / 協力会社P&L / 駐車場 / 会計 / 顧客 / タスク管理 / データ / 過去 / 免許証
⚠️ アイコン右肩の数字バッジ＝未処理件数（配車待ち・じゃらん未完了など）。0件なら非表示。

月切替

配車表・OPシート・データ・経営管理など各画面で対象月を切り替えます。

場所：各画面上部の「◀ 2026/6 ▶」セレクタ
  1. 画面上部の年月表示の左右矢印で前後月へ移動。
  2. 配車表はさらに 月／週／日 のビュー切替あり。

PWA / キャッシュ更新（最新版にする）

古い画面が残る・修正が反映されない時にキャッシュを更新します。

場所：ブラウザ／ログイン画面の「キャッシュクリア」ボタン
  1. 通常はAPPを開くと自動でバージョン検知してリロードされる。
  2. 反映されない時：ログイン画面の「キャッシュクリア」ボタンを押す。
  3. iPhoneで頑固な時：設定→Safari→「履歴とWebサイトデータを消去」。
  4. ホーム画面アイコンのPWAは「アイコン削除→URLから再追加」が確実。
⚠️ 現在 APP_VERSION v4.7.232 ／ キャッシュ spk-v777。下部の同期ステータスが 🟢同期中 なら最新接続。

📥 2. 予約管理▶

メール自動取込（GAS）

OTAの予約確定メールを自動でDB登録し、自動配車まで行います（基本は無人）。

場所：GAS「札幌予約メール自動配車」（自動・15分間隔）
  1. OTA（じゃらん/楽天/skyticket/エアトリ/RC/GoGoOut/HP）からメール受信。
  2. 15分以内に reservations 登録＋空車へ自動配車＋OPタスク生成。
  3. 結果は #sapporo_reservation に通知される。
⚠️ 取りこぼし疑い時は「データタブで予約番号検索」。登録はされているが日付/車両が空＝配車表に出ないだけのこともある。

Slack 予約登録（手入力をSlackから）

メールに乗らない予約をSlack投稿1つで登録＋自動配車します。

場所：Slack #sapporo_reservation（1分間隔で取込）
  1. 定型フォーマットで投稿（予約者名・クラス・貸出/返却日時・届先 等）。
  2. クラスは A/B/C/S/F/H、または車種名（CX-5・ノア等）でも自動判定。
  3. 1分以内にスレッド返信で「✅予約登録＋配車完了」。
⚠️ 届先ラベルは「届先/配達先/受取場所」等の表記ゆれOK。クラス無効時はスレッドにエラー理由が返る。

CSV取込

OTA予約CSVを一括インポートし、既存との差分を確認して登録します。

場所：CSV取込タブ（📁）
  1. CSVファイルを選択してアップロード。
  2. 差分（新規／変更）を画面で確認。
  3. 内容を確認して取込を確定。
⚠️ 乗車人数は最大8人で自動クランプ。場所の手入力は元メールと照合してから。

手動登録・変更・キャンセル

データタブで予約を直接編集・キャンセルします。

場所：データタブ（📋）
  1. 該当予約の行を開いて編集（料金・場所・時間・担当 等）。
  2. キャンセルはCXLボタン → 2段階確認（確認ダイアログ→予約番号入力）。
  3. 保存すると配車表・OPシートにも即反映。
⚠️ 誤タップ防止のためキャンセルは2段階。スタッフ手入力（担当・場所・料金）は自動処理で消えない設計だが、入力後は保存を確認。

🚗 3. 配車・当日業務▶

配車表（FleetTimeline）

車両×日付のタイムラインで予約・メンテ・入庫を一覧し、ドラッグで配車します。

場所：配車タブ（🚗）
  1. 月／週／日 ビューを切替。
  2. 空きセルに予約バーをドラッグで配車。クラス別に色分け。
  3. クラス／車両行に当月売上・台あたり売上・進捗バッジを表示。
⚠️ メンテ（青縞）・別予約（赤）・入庫仮(橙縞)/FIX(緑縞)/変更依頼(マゼンタ縞) のラインには配車しない。空車なしは「配車できる空車がありません」。

OPシート（オペレーション）

当日のDEL/COL/洗車/その他タスクを担当別に管理します。

場所：TOP「📋 OPシートを開く」ボタン
  1. 上部の日付タブで対象日を選択（バッジ＝当日タスク件数）。
  2. スケジュール/DEL/COL/洗車/その他のサブタブで作業を確認。
  3. 担当割当・時間・場所・オプションを編集、ドラッグで並替。完了チェック。
⚠️ PU＝空港出発（緑）／BD＝ヤード出発（赤） を絶対に逆にしない。チャイルド/ベビー/ジュニアシートは数量(×N)まで確認（積込ミス防止）。

当日サマリー・空車ウィジェット

TOPで本日の貸出/返却/整備/洗車・クラス別空車数を一目で確認します。

場所：TOP（空車ウィジェット／タスクサマリー／本日スケジュール）
  1. 空車数のシグナル色：0=赤 / 1=黄 / 2+=緑。
  2. 空車＝稼働フラグあり＋本日予約期間外＋整備なし＋当日洗車タスクなし。
  3. 個人別タスクサマリーで担当者ごとの当日作業を確認。

エリア区分の注意

配車・価格・調査での札幌エリアの扱いです。

場所：配車・価格表・調査 全般
⚠️ 新千歳空港（千歳市）は札幌（札幌市）とは別エリア扱い。配車・価格設定・SNS・OTA調査すべてで区別する。

💳 4. 決済・会計▶

じゃらん事前決済（Square自動発行）

じゃらん予約に対しSquare決済リンクを自動発行・メール送信し、入金を自動確認します。

場所：決済タブ（💳）／TOP決済セクション
  1. じゃらん予約メール取込で自動的にSquareリンク発行＋お客様へメール送信。
  2. 入金はSquare Orders APIで自動確認 → ステータスが「入金済」に。
  3. TOP「じゃらん事前」アイコンに未決済件数・金額バッジが出る。
⚠️ 請求額＝じゃらん「利用者への請求額」（クーポン/ポイント差引後）。出発3日前に未決済はSlack＋TOP Handoverでアラート。

Square請求（立替・予約外売上）／レシートOCR取込

立替・予約外売上の請求と、レシート画像からの会計自動起票を行います。

場所：会計タブ（💰）／Slack #payment_sapporo
  1. Slackに「品目：」投稿でSquare請求リンクを発行（立替・予約外売上）。
  2. レシートは #payment_sapporo に「画像＋"カード/現金＋科目"」で投稿→OCRで会計自動登録。
  3. 入金済みは自動消し込み。Handoverに未収が残らないか確認。
⚠️ 入金通知は店舗別：札幌＝#payment_sapporo。那覇の通知が札幌に来るのは禁止。読めないレシート画像は除外される。

会計タブ（出納・集計）

現金入出金・予約外売上・立替金を記録し、科目別に集計します。

場所：会計タブ（💰・コード1121）
  1. 3KPIカード（売上/支出/純収支）＋現金入金/出金/残高/立替を確認。
  2. 💸支出項目別 合計表（科目・現金/カード/立替・構成比）を確認。
  3. 年次モードでは📈年間推移（売上/支出/純収支）を常時表示。
⚠️ データは spk_accounting（type＝income/expense/advance/extra_sales/card_pay/cash_out）。月初残高はDB同期（全端末共通）。

🔧 5. 車両▶

車両タブ（マスター・整備）

車両マスタの登録・編集、保険/リース/車検/点検費、整備・距離管理を行います。

場所：車両タブ（🔧）
  1. 5サブタブ：運用サマリー／マスター／車検・点検／距離管理／整備管理。
  2. 運用サマリーに🔴車検・🟡半年点検アラートバナー。
  3. マスターで保険(月額)/リース/車検/点検/自動車税・クラスを編集。
⚠️ クラスは A/B/C/S/F/H ＋ 預かり A2/B2。insurance_annual はフィールド名だが意味は月額。

車両ランキング

全車両の売上・稼働率・粗利を固定式で点数化（S/A/B/C/D）して比較します。

場所：車両ランキングタブ（🏆）
  1. クラス別ランキングと全車両ランキングを表示。
  2. ①合計売上 ②月平均 ③稼働率 ④固定費 ⑤予想粗利 で評価（起点2026-02）。

協力会社（パートナー）車両

預かり車両を配車システムに載せ、協力会社専用ビューで在庫調整・請求・入庫を管理します。

場所：会計セクション「🏢協力会社」／partner.html
  1. 車両マスターで所有者＝協力会社に設定（A2/B2 等）。配車表では紫色表示。
  2. 協力会社は partner.html?owner=ID で自社車両のみ操作。
  3. 入庫スケジュール・請求書格納・キャンセル履歴も同ビューで確認。

傷チェックAPP連携

車両の傷・ヘコミを記録し、お客様へ共有URLで案内します。

場所：傷チェックAPP https://nosh2318.github.io/handyman-damage/
  1. 貸出前に傷チェックを記録（札幌は vehicles と連携）。
  2. OPシート・TOPの📤アイコンから「LINE案内文＋共有URL」をコピー→お客様へ送付。

👥 6. スタッフ▶

出勤簿（シフト）

月別シフト表を作成・編集します。

場所：出勤簿タブ（📅）
  1. 対象月を選択し、スタッフ×日のシフト記号を入力（●出勤/公/希/有/出 等）。
  2. 保存すると勤怠・給与・タスク管理（出勤日表示）に連動。

給与

勤怠から給与（予算/実績/明細）を計算します。

場所：給与タブ（⏰・コード1823）
  1. 月を選択 → 予算/実績/残業 サブタブで確認。
  2. スタッフ別の明細（基本給・時給・交通費）を表示。
⚠️ 月給/時給 複合：固定曜日は月給内包、固定曜日外のヘルプ出勤は時給×時間を上乗せ（休憩控除なし）。固定曜日が空だと複合が効かない。

勤怠管理

有給・希望休・残業を集計して規定超過をチェックします。

場所：勤怠管理タブ（📋・kintai.html）
  1. 正社員のスタッフカードで年度の希望休（16日制）・残業を確認。
  2. 超過は赤、欠勤ありは黄でアラート。⚙️で調整枠等を設定。

免許証

お客様の免許証画像をアップロード・確認します。

場所：免許証タブ（🪪・license.html）
  1. license.html を開き、予約に紐づく免許証画像を確認/アップロード。

📊 7. 経営・分析▶

経営管理（ダッシュボード／解析）

売上4分解・稼働率・OTA構成・車両別P&Lなど全KPIを集約します。数字はここから読む（再集計しない）。

場所：データ・分析「🔒経営」タブ（コード1823）
サブタブ📊ダッシュボード / 📸月次スナップショット記録 / 📝売上入力 / 📘月次PL/CF / 🔵HP-CV / 📈投資回転率 / 🔬解析 / 🩺データ健全性
解析 内訳A.稼働率 / B.予約・売上(売上4分解) / C.リードタイム / D.構成分析(OTA別・場所Top20・エリア・時間帯) / E.車両別P&L
⚠️ 稼働率は 解析タブA の表示値が正本（自前計算しない）。売上4分解＝基本+付帯-割引+予約外。当月・未来月は途中値。

予算実績（PL/CF）・実入金CF・コスト内訳

PL（売上−支出＝営業利益）とCF（入金−支出）の予算・実績・予実比較を見ます。

場所：予算実績タブ（📊 monthly.html）／実入金CF（💵 cf-cash.html）／コスト内訳（costmatrix.html）
  1. 予算実績：PL/CF × 予算/実績/予実比較 × 那覇/札幌/合計 を切替。
  2. 実入金CF：OTA別入金サイクルで入金月に振替表示。
  3. 支出はコスト内訳タブの表示値を使う（生キー直読みしない）。
⚠️ コスト内訳→実入金CFの順で開く（localStorage連携）。リースは車両マスタ自動＋手動上書き可。

売上予測・運用戦略・収支シミュ

着地予測・予算シナリオ・台数×稼働の収支試算を行います。

場所：データ・分析「📈運用戦略」(strategy.html) / 「🧮収支シミュ」(sim.html)
  1. 運用戦略：🔮売上予測(forecast.html) / 💴予算シナリオ(action-fill) / 📣OTA運用戦略 を1画面に統合。
  2. 収支シミュ：クラス別 台数・稼働・原価を動かすと月次/年間P&L・貢献/台が即計算（実績ライブ自動取得）。

価格表・価格戦略・顧客

シーズナル価格の確認・編集、顧客リピーター分析を行います。

場所：価格表(🗓️ seasonal)／価格戦略(💰 price-hub.html)／顧客(👑)
  1. 価格表：日別ティア（A繁忙/B通常/C閑散）×クラス基本料金を確認。
  2. 価格戦略マスターで編集（シーズナル定義・係数）。
  3. 顧客タブでリピーターを分析。

🆘 9. トラブル対応▶

画面が真っ白／ログインできない

表示が崩れた・先に進めない時の手順です。

  1. ログイン画面の「キャッシュクリア」ボタンを押す。
  2. iPhone：設定→Safari→「履歴とWebサイトデータを消去」。
  3. PWAアイコンは削除→URLから再追加。
  4. ログインボタン無反応はキャッシュ起因が多い（上記で解消）。
⚠️ 「⚠️オフライン」バナーが出てもデータが表示されていれば通信は生きていることが多い。まずリロード。

予約が配車表に出ない

取込されたはずの予約が見当たらない時。

  1. データタブで予約番号を検索（登録自体はされていることが多い）。
  2. 貸出/返却日・車両が空＝配車表に出ないだけ → 手動で日付/車両を補完。
  3. 本当に未登録なら #sapporo_reservation 再投稿 or 手動登録。

数字が合わない時の「正本」

KPIは決まった場所から読む（複数経路で再計算しない）。

稼働率経営管理 → 解析タブ A
売上4分解経営管理 → ダッシュボード／解析タブ B
OTA構成比・場所・時間帯経営管理 → 解析タブ D
車両別売上・粗利・点数車両ランキング（🏆）
車両別P&L経営管理 → 解析タブ E
支出・コスト内訳予算実績 → コスト内訳（costmatrix.html）
PL/CF予算実績タブ（monthly.html）
月次確定値monthly_snapshots（過去確定月）。当月・未来は途中値
⚠️ 当月・未来月の稼働率/売上は「途中値」（直前予約で上振れ）。確定実績として扱わない。
