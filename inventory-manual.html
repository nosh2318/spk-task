📦 在庫管理 操作マニュアル

HANDYMAN札幌店 ／ これから貸し出す予約の「対応状況」を1画面で管理します。Slackスタンプ管理の置き換え＝見落とし防止が目的です。

1. ページの開き方

アプリTOP →「📦 在庫管理」アイコン（または上部タブの📦）をタップ。
アイコンの赤いバッジ＝未対応の件数です。

2. 色の意味（一番大事）

赤　新規・未対応 → まず対応する
橙　在庫調整がまだ残っている
紫　キャンセル → 在庫の開放が必要
白　対応済み（OK）
上の「🔴 未対応のみ」ボタンを押すと、残っている予約だけ表示できます。

4. 3つのチェックの役割

在庫調整　… 自分で手チェック。在庫を押さえたら✓
APP取込　… 自動で✓（基本さわらない）
メール送信… 自動で✓。楽天だけ手動→送信後に自分で✓

5. 通常の予約が入ったとき

  1. 赤い行を確認する
  2. 在庫を押さえる作業をする
  3. 「在庫調整」に✓ → 白くなればOK
  4. 楽天はメール送信後に「メール送信」も✓

6. キャンセルが入ったとき

基本ルール：キャンセルは「在庫管理」から行う（配車表からではなく）

1. 予約番号の横にある ✕取消 ボタンを押す
2. 確認 → 予約番号を入力 → 決定
3. これでアプリ上もキャンセルになり、配車も自動で外れます

その後：
・すでに在庫調整していた予約 → 紫の「在庫開放」待ちで残る → 在庫を空けたら「在庫開放」に✓
・まだ在庫調整していない予約 → 表から自動で消えます（やること無し）
⚠️ オフィシャルサイトのキャンセルは自動通知が来ません。気づいたら必ず「在庫管理」から ✕取消 してください。
楽天など他社の自動キャンセルは今まで通り自動で反映されます。
💡 もし先に配車表からキャンセルしても大丈夫。その場合も在庫管理に「在庫開放」待ちとして自動で出てきます（逆手順OK）。

7. その日のゴール

画面上の「未対応」が 0 になれば、その日の在庫対応は完了です。
チェックは全員の端末に即共有されます（誰がやってもOK）。
