🧑 人間がやること ＝ 洗車・検査・現地対応（免許証撮影/鍵渡し/忘れ物・給油・傷確認）・ボタンを押す・依頼の承認・手動客へのLINE送信

📱の見分け方（各予約に付いてます）： 📱OK ＝LINE登録済み → AIが自動送信　／ 📱手動 ＝LINE未登録 → 人間がコピーして貼付

1🪪 マイページ対応出発前（予約後〜前日）
予約後、お客様が専用ページで内容を確認・変更する

🧑 人間がやること（管理画面 my-admin）

  1. 🔔変更依頼（オプション/補償/キャンセル/24h以内の場所）を [承認]／[却下]
    → 承認で内容反映＋お客様へLINE自動通知
  2. 場所情報なしの客に、LINE・電話でお届け場所を催促
※ 場所・時間の変更（期限内）は承認不要で自動反映＝人間の作業なし。依頼系だけ承認。

🤖 AIがやること

  • 全予約に固有マイページURLを自動発行→LINEで自動送信
  • お客様の場所・時間の変更を即OPシートに自動反映（お届け24h前まで／回収2h前まで）
  • 変更・依頼を履歴に記録し、Slackへ自動通知
2🧽 洗車傷チェックの前
お客様が気持ちよく乗れる状態に仕上げる
🎯 目的：快適に走行できる状態

🧑 人間がやること

    ボディ・窓ガラス・タイヤ・ナンバー。洗車後は水滴を拭き上げる
  2. 車内を清掃＋消臭
    ゴミ回収・掃除機・拭き上げ→消臭スプレー
  3. オプション（子ども用シート等）を積み込み
    予約内容どおりの種類・個数を確認して車内へ
  4. 車内資料を助手席にセット
    案内書類一式を助手席に設置

🤖 AIがやること

3🔎 検査洗車の後
出発前に車のコンディションを点検する
🎯 目的：安全に走行できる状態

🧑 人間がやること

  1. ガソリン残量
    満タン（規定量）まで給油されているか
  2. タイヤ空気圧
    4輪＋指定があればスペアも確認
  3. ウォッシャー液
    量を確認、少なければ補充
  4. ドラレコ接続状態
    電源ON・録画中ランプ・SDカード挿入を確認

🤖 AIがやること

なし（現場作業）
4🩹 傷チェック出発30分前
お客様に車の傷・ヘコミを事前確認してもらう

🧑 人間がやること（手動客のみ）

  1. TOP「🩹傷チェック送信」を開く
  2. 📱手動の客だけ [📋コピー]→LINE送信→[✅対応]
※ 📱OKの客は自動送信済み＝何もしなくてOK

🤖 AIがやること（基本これで完了）

  • 📱OKの客へ出発30分前に傷チェックURLを自動送信
  • マイページにも傷チェックが表示（出発日8:00〜）
5🚚 出発（お届けに向かう）到着5〜10分前に押す
お客様の元へ車を届けに出発するとき

🧑 人間がやること

  1. 出発前に再確認
    ・ガソリン残量　・ドラレコ接続状態　・オプション（子ども用シート）
  2. お客様に近づいたら（到着5〜10分前） タスクの 🚚出発 を押す
  3. 運転手ページで 📡位置送信を開始 を押す
  4. 📱手動の客だけ：コピーされた案内文をLINEに貼って送信
  5. ページは開いたままにして運転（閉じると位置共有が止まる）
⏱ ボタンは出発直後ではなく到着5〜10分前に押す。遠距離だと長時間の位置共有はお客様・スタッフ双方の負担になるため。

🤖 AIがやること

  • 「出発」を記録（配車状況を更新）
  • 📱OKの客へ追跡URLを自動送信（貼付不要）
  • お客様は地図でスタッフの現在地をリアルタイム確認
6📍 到着（お届け）
お届け先に到着し、お客様に車を引き渡すとき

🧑 人間がやること

  1. 到着したら 📱到着 を押す
  2. 📱手動の客だけ：到着連絡をLINEに貼って送信
  3. 免許証を表・裏 撮影して格納
    運転予定者全員分が必要。不在の方がいる場合は運転開始前にLINEで送信してもらう（必ず1人は原本の確認が必要）
  4. 車の鍵をお渡しする
🌏 インバウンド（外国人）の場合は「パスポート＋国際免許証」。
撮影：①パスポート顔写真ページ ②パスポート入国スタンプページ ③国際運転免許証（念のため全ページ）

🤖 AIがやること

  • 📱OKの客へ「到着しました」を自動LINE送信（車両ナンバー付き）
7🧭 回収に向かう到着5〜10分前に押す
お客様から車を回収しに向かうとき

🧑 人間がやること

  1. お客様に近づいたら（到着5〜10分前） タスクの 🧭回収に向かう を押す
  2. 運転手ページで 📡位置送信を開始 を押す
  3. 📱手動の客だけ：案内文をLINEに貼って送信
  4. ページは開いたままにして移動 → 現地着で「📍到着（回収／手順8）」へ

🤖 AIがやること

  • 「回収に向かう」を記録
  • 📱OKの客へ回収の追跡URLを自動送信
8📍 到着（回収）
回収場所に到着し、車を受け取って返却を完了させる

🧑 人間がやること

  1. 到着したら 📱到着 を押す
  2. 忘れ物確認
    ETCカード・スマホ・充電器・車内の私物
  3. 給油確認
    満タン返却になっているか
  4. 傷確認
    貸出時の状態と照合。新しい傷があれば撮影して報告
  5. 問題なければ タスクの ✅完了 にチェック

🤖 AIがやること

  • 📱OKの客へ到着連絡を自動LINE送信
  • 返却を記録し、翌朝の御礼送信を予約
9🙏 御礼現地＋返却の翌朝
ご利用のお礼をお伝えする

🧑 人間がやること（現地でお礼）

  1. 車の受け渡し時に、お客様へ直接お礼をお伝えする
🗣 お礼スクリプト（例）
「本日はHANDYMANをご利用いただき、誠にありがとうございました。またのご利用を心よりお待ちしております。お気をつけてお帰りください。」

🤖 AIがやること

  • 返却翌朝に御礼メッセージを自動送信（📱OKの客）
※ 設定でON/OFF（現在OFF・稼働開始時にONにする）
